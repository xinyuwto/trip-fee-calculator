## 已实现

旅行记账 AA 分账工具，纯前端 Vue 3 SPA，功能完整可用。

### 页面（4 个）
| 路由 | 视图 | 功能 |
|------|------|------|
| `/` | InitView | 设定旅行名称、成员人数（2-20）、成员姓名 |
| `/expense` | ExpenseView | 支出增删改、JSON 导出导入、重置数据 |
| `/settlement` | SettlementView | 总支出、每人净额、最少转账方案 |
| `/detail` | DetailView | 每笔支出明细（用途、金额、付款人、受益人、均摊） |

### 数据层
- `src/stores/trip.js` — 单例 composable，deep watch 自动写 localStorage
- 金额用**整数分**存储，无浮点精度问题
- 导入/导出：剪贴板 + JSON 文件，校验 + 二次确认

### 分账算法
- 每笔支出在受益人之间**整数均摊**（`Math.floor` + 余数分配）
- 贪婪匹配债权人/债务人 → 最小转账笔数

### 技术栈
- Vue 3 Composition API + Vite + Vue Router 4（hash）
- 零外部依赖（无 UI 库、无状态管理库）
- 移动端优先 CSS，44px+ 触控区域

### 测试
- 17 个单元测试全通过（trip store、settlement、import-export）
- 运行：`npm test`

### 路由守卫
- 未初始化 → 重定向至 `/`
- 已初始化 → `/` 重定向至 `/expense`
