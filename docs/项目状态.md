## 已实现

旅行记账 AA 分账工具，纯前端 Vue 3 SPA，功能完整可用。

### 页面（4 个）
| 路由 | 视图 | 功能 |
|------|------|------|
| `/` | InitView | 设定旅行名称、成员人数（2-20）、成员姓名 |
| `/expense` | ExpenseView | 支出增删改（10 种费用分类 + 备注）、JSON 导出导入、重置数据 |
| `/settlement` | SettlementView | 总支出、每人净额、最少转账方案、"结算依据"入口 |
| `/detail` | DetailView | 按成员分 tab 的结算依据：净额卡片、转账任务、与他人往来、解释说明 |

### 数据层
- `src/stores/trip.js` — 单例 composable，deep watch 自动写 localStorage
- 金额用**整数分**存储，无浮点精度问题
- 添加/修改操作成功后 toast 提示（"添加成功"/"修改成功"，2 秒自动消失）
- 导入/导出：剪贴板 + JSON 文件，校验 + 二次确认

### 分账算法
- `analyzeSettlement()` — 按成员维度输出净额、应收/应付来源、与他人往来、解释说明
- `calculateSettlement()` — 每笔支出在受益人之间**整数均摊**，贪婪匹配债权人/债务人 → 最小转账笔数

### 同步功能（云端共享码同步）
- 8 位共享码：记账页头部「同 步」开启，生成 8 位共享码；同伴输入同步码加入同一旅行，实现多人记账同步
- 推 / 拉：手动「推 送」把本地账单推送到云端、「拉 取」拉取远端最新账单
- revision 冲突：每次推送 revision +1；本地基准落后于远端时进入冲突视图，可「拉取远端」或「用我的覆盖」二选一
- 后端：CloudBase（腾讯云开发）体验版 —— 云函数 `trip-sync`（HTTP 函数）+ `trips` 集合（ADMINONLY 权限）；体验版到期时间 **2027-01-23**
- 兜底：JSON 导入/导出保留为离线兜底，无网络时仍可跨设备传递数据
- 同步状态存于 `trip-fee-calculator-sync`（localStorage）：同步码、baseRevision、我的身份、上次同步时间

### UI 主题
- 纸纹质感设计系统（`src/styles/theme.css`）— CSS 自定义属性
- 主色调：`--paper: #f4ecd8`、`--ink: #1c1917`、`--vermilion: #b54b3a`、`--moss: #4a6b3a`
- 卡片色彩层级：`#fbf6e8`（高亮）、`#fffdf3`（次要）、渐变卡片、透明操作区
- 页面导航按钮（返回、结算依据）统一置于页面顶部 header 中

### 费用分类
正餐、甜点、纪念品、酒店、机票、火车、租车、交通、其他

### 技术栈

- 零外部依赖（无 UI 库、无状态管理库）
- 移动端优先 CSS，44px+ 触控区域

## 已知局限

- 同步为手动推拉，非实时推送；依赖 CloudBase 体验版（到期时间 2027-01-23），到期后需迁移或续费
- 无真实用户认证，任何人拿到同步码即可加入该旅行
- 无网络时仅能使用 JSON 导入/导出兜底同步
